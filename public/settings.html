Hotkeys

These work anywhere on this computer, even when Telestrator is not the focused app:

Clear drawings
Ctrl + Alt + C
Hide / show output on air
Ctrl + Alt + H
Undo last stroke
Ctrl + Alt + Z

On a Mac, use Cmd instead of Ctrl. They are also in the app menu.

Companion / External Control

Any button controller that can send an HTTP request (e.g. Bitfocus Companion with the Generic HTTP module) can control the telestrator. GET or POST both work:

Clear all drawings
Undo last stroke
Hide / show on-air drawings (toggle; also /api/hide, /api/show)
Arm / disarm auto-clear (toggle; ?seconds=N to set delay; also /on, /off)
Switch key mode (also /api/keymode/luma, /api/keymode/chroma)
Status JSON (poll for button feedback: strokes, hidden, autoClear, keyMode)

In Companion: add a Generic HTTP connection, then give a button the GET action with a URL above. Clear cuts instantly. Auto-clear wipes the screen N seconds after the last stroke — the safety net for when the commentator forgets.

Instructions

1. Connect your ATEM program output to the Mac Mini's capture card.

2. Select the capture device above and click Start Capture.

3. Open the Draw URL on your iPad to start telestrating.

4. Open the Output URL fullscreen on this Mac Mini (F11 or Cmd+Shift+F in Chrome).

5. Route this Mac Mini's HDMI output back to the ATEM as a source.

6. On the ATEM, set up a luma key on the telestrator source (black background drops out), then use it as a downstream key over your program.
